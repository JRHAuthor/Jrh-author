# J.R.H. Author Website

## Files to upload to GitHub

Upload everything inside this folder to the root of your `Jrh-author` repository:

- `index.html`
- `styles.css`
- `script.js`
- the entire `assets` folder

Replace your old `index.html` when GitHub asks.

## On an Android phone

1. Download and unzip `jrh-author-site.zip`.
2. Open your `Jrh-author` repository on GitHub.
3. Tap the three dots beside the green **Code** button.
4. Choose **Upload files**.
5. Select `index.html`, `styles.css`, `script.js`, and all four images in `assets`.
6. Commit the changes to the `main` branch.

GitHub may take a few minutes to update the live website.
